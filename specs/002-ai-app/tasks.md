# Part 1B tasks

## Task breakdown

1. Build the AI-like briefing generator.
2. Add explicit field-level validation rules.
3. Generate and log structured evidence for failures.
4. Summarize the final review decision.

## Definition of done

- The generator produces variability without violating policy.
- The validator enforces the spec independently.
- Failures are captured and traceable.
- Human acceptance is documented.
